01 About

A full-stack engineer who opens the hood.

Hi — I'm Sivani. I'm a full-stack software engineer and Flutter developer who's happiest moving across the whole stack: frontend, backend, mobile, and the database underneath it all.

On the job, that's meant shipping cross-platform Flutter and React interfaces wired up to REST and GraphQL APIs, translating Figma mockups into pixel-perfect, responsive UI, and building Python (Flask) and PostgreSQL backends end-to-end — schema design, tests, and deployment.

What I really enjoy, though, is opening the hood on the things most of us just import and trust. I don't like treating a vector database or a consensus protocol as a black box, so in my own time I've rebuilt pieces of that machinery from scratch — a vector search engine, an ML drift-monitoring platform, a Raft consensus simulator, and more, all shown below. I hold the IBM AI Developer Professional Certificate, and I'm always looking for the next system I don't fully understand yet.
