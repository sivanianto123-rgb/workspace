What this is

ModelWatch trains binary classifiers, serves predictions, logs every scored request, and continuously compares the live input distribution against the training baseline using PSI and the Kolmogorov–Smirnov test. When too much of the feature space drifts, it retrains automatically.

Core API

POST /api/trainTrain a model (model_type, hyperparams)
POST /api/predict/<run_id>Score rows and log them
GET /api/drift-check/<run_id>PSI + KS drift report
POST /api/check-and-retrain/<run_id>Drift check with auto-retrain
GET /healthLiveness probe
